# grind-scan

Scanner de code-barre en direct de [Grind](https://github.com/Hontans/grind), publié sur GitHub Pages.
Sur iPhone, le cadre de Google Apps Script bloque la caméra : l'app ouvre cette page dans un onglet,
qui filme, lit le code (zxing-cpp en WebAssembly) et le renvoie à l'app. Aucune donnée ici.

Source : `scan/index.html` du dépôt grind (copie à garder identique).
