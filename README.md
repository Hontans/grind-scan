# grind-scan

Pages publiques de [Grind](https://github.com/Hontans/grind), sur GitHub Pages. Aucune donnée ici.

- `app/` : l'app Grind elle-même, en plein écran hors du cadre Google (construite par `tools/build-web.js`
  du dépôt grind, ne pas modifier à la main). Elle lit et écrit le Google Sheet par le script Apps Script,
  avec une clé donnée par le menu « Grind → Ouvrir l'app » du Sheet.
- `index.html` : scanner de code-barre de secours (copie de `scan/index.html` du dépôt grind).
